RUTINA – paquete PWA

Este paquete convierte tu HTML en una aplicación web instalable (PWA).

INSTALACIÓN EN ANDROID
1. Sube TODO el contenido de esta carpeta a un alojamiento HTTPS estable.
   Una opción gratuita es GitHub Pages.
2. Abre en Chrome Android la dirección HTTPS donde hayas subido los archivos.
3. Abre el menú ⋮ y pulsa «Instalar aplicación» o «Añadir a pantalla de inicio».
4. La app aparecerá con el nombre «Rutina» y su propio icono.

IMPORTANTE SOBRE TUS DATOS
- La aplicación guarda tareas y registros en localStorage del navegador/app.
- Los datos permanecen en ese dispositivo y en ese origen web; no se sincronizan automáticamente con otros móviles.
- No borres los datos/almacenamiento de la aplicación ni los datos del sitio web, porque podrías perder el seguimiento.
- Antes de empezar a introducir muchos datos, prueba crear una tarea, cerrar y volver a abrir la app.

CONTENIDO
- index.html: tu herramienta original, adaptada para PWA.
- manifest.webmanifest: nombre, icono y modo de apertura.
- service-worker.js: caché para permitir abrir la app tras la primera carga.
- icons/: iconos de la aplicación.

Se necesita HTTPS para instalar una PWA correctamente (salvo localhost para pruebas).
